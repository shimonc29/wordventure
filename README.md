# WordVenture

משחק אינטראקטיבי ללימוד אנגלית לכיתה ו׳.

## פרסום ב-GitHub Pages

1. יוצרים מאגר חדש ב-GitHub ומעלים אליו את תוכן התיקייה.
2. נכנסים ל-Settings → Pages.
3. תחת Source בוחרים GitHub Actions.
4. לאחר סיום הפעולה האוטומטית יופיע הקישור למשחק.

ההתקדמות נשמרת אוטומטית בדפדפן של השחקנית.
